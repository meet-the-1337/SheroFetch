QUICK START:
------------------------------------------------------------------------
1. FIRST TIME SETUP (Recommended):
   Double-click "setup_windows_prerequisites.bat"
   This script will verify your Python environment and automatically
   install required dependencies (requests, mutagen, pillow, yt-dlp, ffmpeg)
   so that all downloads, album art, and FLAC conversions run with ZERO errors.

2. LAUNCHING THE APP:
   Simply double-click "SheroFetch.exe" (or "SheroFetch-Windows-x64.exe").
   Alternatively, you can run "launch_music_downloader.bat".

3. USING SHEROFETCH:
   - Search for songs directly by name or artist.
   - Paste links from Spotify, YouTube, YouTube Music, or Apple Music.
   - Batch import song titles from CSV or text files.
   - Use the built-in 10-band Equalizer and Spectrum Visualizer.
   - Under Settings, choose your Music Vault folder where songs are saved.

AUDIOPHILE 1:1:1 FOLDER STRUCTURE:
------------------------------------------------------------------------
All acquired songs are strictly organized using the audiophile 1:1:1 standard:
   <Music_Vault>/<Artist>/<Album>/<Artist> - <Title>.flac (or .mp3)
   along with:
   - cover.jpg (high-resolution embedded album artwork)
   - <Artist> - <Title>.lrc (millisecond-synced lyrics)

PREREQUISITES INCLUDED IN THIS PACKAGE:

- SheroFetch.exe (Native Windows 64-bit GUI executable)
